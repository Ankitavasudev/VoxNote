# VoxNote

![CI](https://github.com/Ankitavasudev/VoxNote/actions/workflows/ci.yml/badge.svg)

Voice-to-text note-taking app with AI summarization and organization.

## Features

- **Voice Recording** - Record your thoughts with one click
- **AI Transcription** - Convert speech to text automatically
- **Smart Summarization** - AI-powered note summaries
- **Tags & Folders** - Organize notes with tags and folders
- **Search** - Full-text search across all notes
- **Export** - Export notes as Markdown or PDF

## Tech Stack

- React.js
- Web Speech API
- OpenAI API
- LocalStorage

## Installation

`ash
npm install
npm start
`

## Usage

1. Click the microphone to start recording
2. Speak your note
3. AI will transcribe and summarize
4. Organize with tags and folders

## Development

`ash

npm run build
